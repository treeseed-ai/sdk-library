title: Select accepted decisions in portable workday intent
request: "Add decisionIds?: string[] to WorkdayIntent and expose it exactly once
  as repeatable/comma-separated --decision input for workdays plan. Validate
  bounded nonblank identities and reject duplicates after trimming. Normalize
  the IDs into deterministic lexical order in the portable request handed to the
  API; the API remains the authority that computes intent and preflight digests
  from that normalized request. Retain agentSelection, allocation, profile,
  project, timing, and communication inputs because they are high-level workday
  policy—not derived capacity state. Retire operatorConstraints and reject
  caller-authored graph, executionPlan, capacityPlan, demand, assignment,
  source, role, estimate, reservation, usage, and provider-selection fields
  without aliases."
summary: Prove the SDK can express high-level decision-governed execution while
  keeping all derived execution state API-owned.
status: draft
