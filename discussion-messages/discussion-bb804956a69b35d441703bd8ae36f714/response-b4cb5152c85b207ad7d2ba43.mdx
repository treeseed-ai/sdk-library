Yes, the SDK exposes `npm run lint`, and release verification runs it. However, it currently aliases `npm run build:dist`; there is no dedicated ESLint, Biome, or Prettier configuration. So today “linting” means verifying that the TypeScript distribution builds successfully, supplemented by file-architecture checks and contract tests—not enforcing a standalone code-style rule set.
