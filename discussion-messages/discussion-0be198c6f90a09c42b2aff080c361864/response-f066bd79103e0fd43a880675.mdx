Yes, but it is build-based rather than a conventional style linter. `npm run lint` runs `npm run build:dist`, which compiles the TypeScript and emits declarations under strict compiler settings. No ESLint, Biome, or Prettier configuration or dependency is present.

The release-verification workflow runs this lint script, plus file-length and architecture checks, standards validation, and contract tests. So the SDK enforces compilation and structural correctness, but currently has no dedicated code-style linting rules.
