Yes, but only nominally. The SDK defines `npm run lint`, but it aliases `npm run build:dist`; there is no dedicated ESLint, Biome, or similar configuration or dependency.

So the current “lint” check is effectively a strict TypeScript/declaration and esbuild build check. CI runs the broader `npm run verify:direct` release-verification path, not a standalone style linter.
