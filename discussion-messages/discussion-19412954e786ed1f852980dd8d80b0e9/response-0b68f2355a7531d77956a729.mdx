Yes, but the current `lint` script is a build/type-validation gate, not a conventional style linter. `npm run lint` aliases `npm run build:dist`, which compiles with esbuild and generates TypeScript declarations under strict TypeScript settings.

It is enforced by `npm run release:verify`, and CI runs that verification for pull requests and protected-branch pushes. I found no ESLint, Biome, or similar formatting/style-lint configuration at revision `ac6a535b99867cfc9e955b71ec333ed28980020a`.
