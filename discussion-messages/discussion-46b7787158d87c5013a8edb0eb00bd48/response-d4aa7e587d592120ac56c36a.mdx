No: the SDK explicitly does not own server-side execution, because the project README states it "does not own control-plane persistence, scheduling, repository mutation, content publication, deployment, provider runtimes, or server-side business workflows," and the core objective likewise says SDK "must not ... run provider execution" because those implementations belong to the API or dedicated runtime packages.
