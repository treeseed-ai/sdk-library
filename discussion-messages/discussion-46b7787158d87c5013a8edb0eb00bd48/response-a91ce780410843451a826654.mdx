The SDK codebase is a portable TypeScript package that defines TreeSeed’s shared wire contracts, standards, and typed remote clients rather than owning server-side execution or product workflows: the README positions `@treeseed/sdk` as the contract and client layer for control-plane, TreeDX, agent, CLI, and browser integrations, while the exported surface in `package.json` reinforces that boundary through explicit subpath entrypoints instead of a catch-all root export. Concretely, I inspected `src/entrypoints/clients/control-plane-client.ts`, which implements the typed control-plane client, request normalization, and RFC 9457-style problem handling, and `src/operator-contracts/catalog/control-plane-catalog.ts`, which builds the immutable operation catalog from the SDK’s authoritative control-plane bindings.
